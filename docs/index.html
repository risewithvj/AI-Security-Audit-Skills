FAQ

  

    
Is my code safe?
Yes. The audit is read-only and recommendations only — it never modifies your code. The web prompt runs inside the AI you already use; this page itself runs no code on your source and sends it nowhere. Strip .env and real secrets before zipping, as a habit.

    
What is DPDP?
India's Digital Personal Data Protection Act, 2023 (with the DPDP Rules, 2025). The DPDP pass maps where personal data is collected, stored, logged, shared, retained and erased, and checks notice, consent, security safeguards, breach readiness, retention/erasure, data-principal rights, children's data and cross-border transfer — against your actual code.

    
Free vs paid AI — which do I use?
Free or smaller AIs get Lite: top risks in a one-page report that fits a tight context. Paid tiers (Plus / Pro / Advanced / Max / Ultra) can hold the whole zip and run the full Pro audit, with God and the Deep 4-pass for the most thorough review.

    
Why zero false positives?
The benchmark target, OWASP Juice Shop, is deliberately vulnerable — so there is little to falsely claim, and "0 false positives" there measures precision only on known-vulnerable code, not real-world noise. Every confirmed finding still must carry file-and-line proof before it is reported.

    
Does it fix my code?
No. It is recommendations only. You get the smallest safe fix described for each finding, but nothing in your project is changed, formatted, committed or installed into.

    
Which AI is best?
In our benchmark the AISA CLI engine led by a wide margin (Core 25/30). Among web AIs, Codex and Claude.ai edged out ChatGPT, and Gemini Pro refused — but the web runs were not apples-to-apples (partial runs, softer prompt). See the scorecard for the honest detail.

We then record which prompts/links you click — never your audit content — and advertising signals stay denied. Click Decline to keep it all off.
