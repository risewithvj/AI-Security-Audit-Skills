2Free AI vs paid AI

    
Why both exist: free AIs have a smaller context window and shorter run time, so they get a tight one-page Lite audit; paid tiers can hold the whole zip and run the full multi-phase Pro (and God) audit.

    

      

        
Free AI Lite

        
For free or smaller models. Top risks only, in a single-page report so it finishes inside a tight context and time budget.

        
    
          
  • MODE=lite — top risks, one page
    • 
          
  • Still proof-backed: file, line, attack, result
    • 
          
  • Includes the client-side tampering pass and a "Not checked" list
    • 
        

      

      

        
Paid AI: Plus / Pro / Advanced / Max / Ultra Pro / God Mode

        
For paid tiers with large context. Runs the full six-phase audit, folding in the DPDP pass automatically when personal data is found — and God Mode adds the deep-dive extras.

        
    
          
  • MODE=pro — full six-phase audit + auto DPDP
    • 
          
  • MODE=god — adds self-refutation, risk chains, impact scenario, fix-priority roadmap, resume note
    • 
          
  • Best when the whole project fits in one pass
    •
